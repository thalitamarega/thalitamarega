## 💎 Projeto em destaque — THATA Catalog

**Um catálogo de body piercing que conecta a descoberta de uma joia à consulta pelo WhatsApp.**

[Acessar o catálogo](https://thata-catalogo.vercel.app) · [Explorar o código](https://github.com/thalitamarega/catalog)

### O problema

Apresentar uma coleção de joias de forma organizada e permitir que a pessoa encontre peças, monte uma seleção e consulte a disponibilidade em uma conversa.

### A solução

Uma aplicação web com busca, filtros, paginação e seleção de várias peças. A seleção vira uma mensagem organizada para o WhatsApp, facilitando o atendimento.

| Parte do projeto | Como foi implementada |
| --- | --- |
| Experiência de navegação | Interface responsiva em React, Next.js e TypeScript |
| Descoberta de produtos | Busca com normalização de acentos, filtros e paginação |
| Consulta de disponibilidade | Mensagem de WhatsApp com as peças selecionadas |
| Dados do catálogo | Integração com Supabase e cópia local de reserva |
| Imagens | Alternativas de carregamento e scripts de auditoria |
| Apresentação visual | Elemento 3D interativo com Three.js |

### Aprendizados na prática

- Lidar com textos inconsistentes e normalizar dados para exibição e busca.
- Planejar alternativas quando dados ou imagens não carregam.
- Conectar estados de interface a uma ação útil para quem usa o produto.
- Organizar scripts para manutenção do catálogo e das imagens.

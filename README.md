## Projeto em destaque

### [THATA Catalog](https://github.com/thalitamarega/catalog)

Catálogo responsivo de body piercing criado para facilitar a descoberta de produtos e a consulta pelo WhatsApp.

**Destaques técnicos:**
- integração resiliente com API externa e fallback de dados;
- busca, filtros, paginação e seleção de várias joias;
- tratamento de dados duplicados, textos corrompidos e imagens inconsistentes;
- interface em React/Next.js e hero 3D interativa em Three.js;
- scripts Node.js para auditoria de qualidade das imagens.

**Stack:** Next.js, React, TypeScript, Supabase, Three.js, Node.js e Vercel.
